# 🏠 Cloud Hostel Complaint System

A cloud-based web application that allows hostel students to submit complaints online and enables administrators to manage, review, and update complaint status.

## 📌 Features

* 👨‍🎓 Students can submit hostel complaints
* 📝 Students can view their submitted complaints
* 🔄 Track complaint status
* 👨‍💼 Admin can view all complaints
* ✅ Admin can update complaint status
* ☁️ Cloud-based data storage
* 🔐 Authentication and secure access
* 📱 Simple and user-friendly interface

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js
* **Database:** Firebase / Cloud Firestore
* **Authentication:** Firebase Authentication
* **Cloud Services:** Google Firebase
